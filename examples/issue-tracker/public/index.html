Bugboard EXAMPLE

Fix bugs with the agent you already have

Bugboard is a team issue tracker. On any issue, click Fix with my agent: your own Codex or Claude Code fixes it in the project folder on your computer and reports back here. Bugboard never sees your code or your AI account.

Quick pick:

Each demo user gets their own copy of the acme-web project, so you won't see anyone else's runs.

How it works

  1. Connect Remote ACP Bridge once and pick the project folder (choose Can edit so the agent can apply its fix).
  2. Open an issue and click Fix with my agent. Approve the task in the desktop app.
  3. The agent works locally, then comments and moves the issue to In review through Bugboard's tools.
