# acme-web (sample project)

Tiny storefront helpers used by the Bugboard example's demo issues.

- `src/slugify.js`: product titles to URL slugs (`/products/<slug>`)
- `src/formatPrice.js`: minor units (cents) to a localized price string
- `src/parseQuery.js`: query strings to plain objects for the search page

Run the tests with `npm test` (Node.js 20+, no dependencies).
